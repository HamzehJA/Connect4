# Connect4 Game in Java

![Connect4 Logo](src/Icons/Connect4.1.png)

## Overview
Connect4 is a classic 2-player game where players take turns to drop colored chips into a grid, and the first player to connect four chips vertically, horizontally, or diagonally wins the game.

This project is implemented in **Java** using **Object-Oriented Programming (OOP)** principles, with a graphical user interface built using **Java Swing**.

---

## Features
- **Interactive GUI**: User-friendly interface with visual feedback.
- **Multiplayer**: Play with a friend by taking turns to place chips.
- **Win Detection**: Detects horizontal, vertical, and diagonal connections of four chips.
- **Win Screen**: Displays a victory message with the winning player (Red or Yellow).

---

## Getting Started

### Prerequisites
- Java version **8** or above installed on your machine.
- An IDE (e.g., IntelliJ IDEA, Eclipse) or a terminal with a compiler to run Java programs.

### How to Run
1. **Clone** or **Download** the repository.
2. **Navigate** to the project folder in your terminal or IDE.
3. **Compile** and **Run** the `Main.java` file.
4. The game will start, and you can begin playing by clicking on the grid.
